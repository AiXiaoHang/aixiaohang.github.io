> **题目类型：** Reverse / 逆向工程基础  
> **使用工具：** IDA Pro 9.3  
> **核心方法：** 静态分析，识别汇编指令中的 ASCII 码，还原 Flag  

---

## 一、 题目分析

下载题目附件，得到一个名为 `baby.exe` 的可执行文件。

**解题思路：**
直接双击运行程序，出现一个黑框（控制台），打印出一句 `Hi~ this is a babyre` 后瞬间消失。这说明它是一个没有交互逻辑的控制台程序，Flag 大概率被硬编码（Hardcode）在程序的汇编代码中。

---

## 二、 解题步骤

### 步骤 1：使用 IDA Pro 加载程序
启动 IDA Pro 9.3，选择 `New`（新建），将 `baby.exe` 拖入工作区。在弹出的加载选项中选择 `Portable executable for 80386 (PE)`，一路点击 `OK` 使用默认设置加载。

### 步骤 2：定位关键函数（main）
在 IDA 的反汇编视图中，默认会停留在 `start` 函数。在左侧的函数列表（Functions window）中，找到 `main` 函数并双击进入。这里存放着程序的核心业务逻辑。

### 步骤 3：分析汇编代码
在 `main` 函数的汇编代码中，我们看到了熟悉的一行：

```assembly
mov     dword ptr [esp], offset Format ; "Hi~ this is a babyre"
call    _printf
```

紧接着下面的代码，是一连串的 `mov byte ptr` 指令。例如：

```assembly
mov     byte ptr [esp+2Eh], 66h ; 'f'
mov     byte ptr [esp+2Eh], 6Ch ; 'l'
mov     byte ptr [esp+20h], 61h ; 'a'
mov     byte ptr [esp+2Ch], 67h ; 'g'
mov     byte ptr [esp+2Bh], 7Bh ; '{'
```

**关键线索：**
IDA 在汇编代码的注释区域，已经自动帮我们把十六进制数转换成了对应的 ASCII 字符（右边引号里的内容）。

将这些字符按顺序拼凑起来，就是完整的 Flag。

### 步骤 4：提取 Flag
根据 IDA 注释中给出的字符序列，我们直接提取出最终答案：

**`flag{Re_1s_S0_C0OL}`**

---

## 三、 关键知识点总结

1. **静态分析：** 当程序无法正常交互运行（如“秒退”）时，使用 IDA Pro 进行静态分析是逆向工程最常用的手段。
2. **识别硬编码（Hardcoded）数据：** 逆向入门题中，Flag 经常以十六进制或 ASCII 码的形式，一条一条地被 `mov` 指令压入栈中。熟悉 ASCII 码表（如 0x66 对应 `f`，0x7B 对应 `{`）能让你快速识别出 Flag。
3. **IDA 注释辅助：** IDA Pro 非常智能，它在解析汇编时会自动将十六进制数换算为对应的字符并在右侧添加注释，极大地方便了我们阅读代码。
