> **题目类型：** Web 基础 / 前端代码审计  
> **使用工具：** 浏览器（Chrome/Edge）  
> **核心方法：** 查看网页源代码，寻找隐藏的十进制 ASCII 编码并解码

---

## 一、 题目分析

访问题目地址，页面可能只会显示一个简单的 `alert` 弹窗，或者看起来“什么都没有”。（如图1，题目描述为 `flag{}`）

**解题思路：** 
在 Web 安全基础题中，如果页面表面没有直接暴露信息，第一反应应该是**查看网页的源代码**。出题人通常会在这里留下隐藏的字符串或编码后的 flag。

---

## 二、 解题步骤

### 步骤 1：查看网页源代码
在题目页面，按下键盘上的 **`Ctrl + U`** 键（或者右键点击页面空白处，选择“**查看网页源代码**”）。

### 步骤 2：寻找编码字符串
在打开的源代码页面中，向下滚动或者使用 `Ctrl + F` 搜索。你会找到一段很长的、由数字组成的字符串（通常以十进制 ASCII 码的形式存在，例如 `102 108 97 103` 这种格式）。这就是被编码隐藏的 flag。

### 步骤 3：解码获取 Flag
将这段十进制数字复制出来，使用在线解码工具或 Python 脚本进行解码：

**使用在线工具：**
打开任意 CTF 常用在线工具网站（如 `CTF在线工具` 或 `Bugku 工具`），找到 **“ASCII 十进制转字符串”** 或 **“十进制转文本”** 功能，粘贴数字，点击解码。得到的明文即为 flag。

**使用 Python 快速解码（推荐）：**
在本地 Python 环境中运行以下代码即可瞬间得到答案：
```python
# 将下方列表替换为你从源码中复制出来的数字
decimals = [102, 108, 97, 103, ...] 
flag = ''.join(chr(i) for i in decimals)
print(flag)
